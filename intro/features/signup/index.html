네 단계면 끝나요

  1. 신청서 링크 보내기

    데스크가 신규 문의자에게 가입신청서 링크를 보내요.

  2. 반 고르기

    아동·성인을 고르면 지금 여유 자리가 있는 반·강사·요일·시간만 보여요.

  3. 제출 즉시 등록

    자리가 있으면 바로 학생으로 등록되고 반에 배정돼요.

  4. 이력 확인

    가입신청 이력에서 등록 완료와 대기 신청을 구분해 확인해요.

정원이 차면 대기 신청으로

선택한 반이 그 사이 다 찼다면 등록 대신 대기 신청으로 받아, 자리가 나면 순서대로 안내해요.

  • 실시간 여유 자리
  • 대기 신청 자동 전환
  • 같은 강사 다른 요일 제안

입회 신청서까지 디지털로

건강 상태, 알레르기, 물 공포심, 방문경로를 학생 상세의 입회 신청서에 기록해 강사와 공유해요.

  • 건강·알레르기 기록
  • 방문경로 통계
  • 종이 서류 없이

궁금한 점

신청 내역은 어디서 보나요?

강습생 관리 → 가입신청 이력에서 모든 신청과 결과를 확인해요.

정원이 찬 반은 어떻게 보이나요?

목록에 나타나지 않아요. 원하면 대기 신청을 받을 수 있어요.

기존 회원은 어떻게 옮기나요?

회원명부 엑셀을 올리면 한 번에 등록돼요.

스케줄·정원 관리

강사·반·시간대별 수업과 정원, 출결, 차량 정보를 한 화면에서 봐요.

자세히 보기 →학부모·강사 앱

학부모는 전화 대신 앱으로, 강사는 출석부 대신 앱으로. 개인 번호 노출 없이 대화해요.

자세히 보기 →보강·결석 관리

학부모가 앱에서 빈자리를 보고 보강을 직접 잡아요. 정원 초과는 자동으로 막아요.
