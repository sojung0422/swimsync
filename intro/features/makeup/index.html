이렇게 사용해요

네 단계면 끝나요

  1. 결석 신청

    학부모가 앱 달력에서 결석할 날짜를 골라요. 여러 날도 한 번에 돼요.

  2. 빈자리 확인

    같은 구분(유치부·정규반·성인반) 반의 빈자리만 추천해 보여 줘요.

  3. 보강 신청

    자리를 고르면 바로 확정되고 보강 잔여 횟수가 자동으로 줄어요.

  4. 명단 자동 반영

    강사 앱 수업 명단과 전체 스케줄표에 보강 학생이 바로 표시돼요.

정원 초과는 신청 단계에서 막아요

반 정원과 강사별 '보강 전용 추가 자리'를 넘는 보강은 학부모 앱에 아예 나타나지 않아요. 강사가 식사·휴식 시간으로 막아 둔 시간에도 보강이 열리지 않아요.

  • 반 정원 + 보강 전용 추가 자리
  • 강사별 보강 안 받는 시간
  • 주 횟수별 보강 가능 횟수 정책

아파서 빠진 날은 서류로 보강·이월

서류가 필요한 보강으로 설정하면 학부모는 진단서 사진과 원하는 처리(보강·이월)를 남기고, 데스크가 검토해 자리를 배정하거나 다음 달 원비에서 이월해요.

  • 아동·성인 따로 서류 필요 설정
  • 데스크 승인 대기·처리 완료 관리
  • 이월은 다음 달 청구에 자동 반영

5주차 대체보강도 자동으로

요일이 다섯 번 도는 달과 세 번만 도는 달을 찾아 1년 치 대체보강일을 제안해요. 확정하면 강사 앱·학부모 앱 달력에 바로 보여요.

  • 연간 대체보강일 자동 제안
  • 휴관일·의무보강일 직접 지정

자주 묻는 질문

궁금한 점

데스크가 보강을 직접 잡는 학원도 쓸 수 있나요?

네. 서류 확인 방식으로 설정하면 학부모는 신청만 하고, 데스크가 검토해 배정하거나 이월해요. 학부모 셀프 방식과 섞어 쓸 수도 있어요.

보강 횟수는 어떻게 제한하나요?

주 몇 회 수강에 보강을 몇 회까지 허용할지 학원 규칙으로 정해 두면, 보강 잔여 횟수가 자동으로 관리돼요.

보강 수업에도 차량이 다니나요?

보강 수업은 차량을 운행하지 않는다고 학부모에게 안내돼요. 결석한 날은 차량 탑승 명단에서도 자동으로 빠져요.

학원 사정으로 보강을 취소해야 하면요?

스케줄에서 보강 취소를 누르면 학부모·강사에게 알림이 가고, 학부모는 앱에서 바로 다시 신청할 수 있어요.
