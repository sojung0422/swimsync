보강·결석 관리

학부모가 앱에서 빈자리를 보고 보강을 직접 잡아요. 정원 초과는 자동으로 막아요.

자세히 보기 →통학 차량 관리

결석·보강이 탑승 명단에 자동 반영되고, 기사님은 앱으로 정류장 순서대로 운행해요.

자세히 보기 →원비 청구·수납

요금제·일할·휴관일·형제 할인·이월까지 반영해 월 원비를 자동 계산해요.

자세히 보기 →스케줄·정원 관리

강사·반·시간대별 수업과 정원, 출결, 차량 정보를 한 화면에서 봐요.

자세히 보기 →반·일정 변경

학부모가 앱으로 신청하고 데스크는 승인만. 적용일부터 모든 명단과 원비가 바뀌어요.

자세히 보기 →강사 급여·실적

정규·프리랜서 급여를 수업 기록으로 자동 계산하고, 강사별 실적을 평균과 비교해요.

자세히 보기 →학부모·강사 앱

학부모는 전화 대신 앱으로, 강사는 출석부 대신 앱으로. 개인 번호 노출 없이 대화해요.

자세히 보기 →온라인 가입신청

여유 자리가 있는 반만 보여 주는 셀프 가입신청서. 제출하면 바로 등록·반 배정돼요.

이어지는 흐름

결석 한 번이 이렇게 이어져요

  1. 학부모 결석 신청

    학부모 앱에서 날짜만 골라요.

  2. 강사·차량 명단 반영

    강사 앱 명단과 기사 앱 탑승 명단에서 자동으로 빠져요.

  3. 보강 셀프 예약

    같은 구분의 빈자리만 보고 학부모가 직접 잡아요.

  4. 원비·급여까지

    이월은 다음 달 원비에, 진행한 보강은 강사 급여 계산에 반영돼요.
