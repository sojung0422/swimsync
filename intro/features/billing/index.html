이렇게 사용해요

네 단계면 끝나요

  1. 원비표 등록

    아동·성인, 주 횟수, 자유수영 포함 여부로 수강 플랜을 만들어요.

  2. 이번 달 청구 생성

    일할 계산, 휴관일, 형제·이벤트 할인, 보강 이월을 반영해 청구서를 만들어요.

  3. 학부모 확인

    학부모 앱 결제 현황에서 이번 달 금액을 보고 결제를 요청해요.

  4. 수납·미납 관리

    카드·현금·계좌이체 수납을 기록하고, 미납은 보호자에게 자동 안내돼요.

중간 등록도 남은 횟수만큼

1회부터 14회까지 횟수별 청구 요금을 넣어 두면 등록일 기준으로 남은 수업만큼 일할 청구해요. 야간 할증처럼 시간대별 추가 요금도 반영돼요.

  • 횟수별 일할 청구
  • 시간대별 추가 요금
  • 휴관일 자동 제외

할인과 이벤트는 자동으로

같은 부모 연락처로 등록된 형제를 자동으로 세어 형제 할인을 적용해요. 이벤트 참여 인증을 받으면 승인 한 번으로 할인이 붙어요.

  • 형제 할인 자동 계산
  • 이벤트 참여 인증 승인
  • 학생별 개별 할인

미납은 놓치지 않게

정해진 날까지 등록비가 확인되지 않으면 보호자에게 매일 안내가 가고, 원장은 대상 학생만 골라 처리해요.

  • 미납 보호자 자동 안내
  • 원장 확인 후 처리
  • 월별 수납 실적 통계

자주 묻는 질문

궁금한 점

중간에 등록한 학생 원비는 어떻게 계산하나요?

횟수별 청구 요금표를 기준으로 등록일부터 그 달에 남은 수업 횟수만큼 청구해요.

휴관일은 원비에서 빠지나요?

학원 휴무일로 지정한 날은 다음 달 청구 계산에서 제외돼요.

보강 대신 이월하면 원비가 줄어드나요?

이월로 처리한 회차만큼 다음 달 청구에서 자동으로 차감돼요.

결제는 어떻게 받나요?

학부모가 앱에서 결제를 요청하면 학원이 수납을 확인해 기록해요. 카드·현금·계좌이체 수납을 모두 기록할 수 있어요.
